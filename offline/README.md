# 법인카드 점검 도구 (오프라인 HTML)

Python과 Claude를 쓸 수 없는 내부망에서 쓰는 점검 도구입니다. **설치 없이 Chrome으로 여는 HTML 파일 1개**이며, 네트워크를 전혀 쓰지 않습니다.

- 반입할 파일: [`dist/법인카드점검_v1.0.html`](dist/법인카드점검_v1.0.html) (약 0.9MB)
- 점검 로직: CLAUDE.md 2장 (R01~R17, T-R1~T-R4, 위험점수·등급, 사전승인 문서번호 기재 건 저위험 조정)

## 보안 특성 (정보보호팀 검토용)

| 항목 | 내용 |
|---|---|
| 외부 통신 | 파일 머리의 Content-Security-Policy로 모든 네트워크 연결을 차단 (`default-src 'none'`, `connect-src 'none'`). 외부 스크립트·글꼴·이미지를 불러오지 않음 |
| 데이터 처리 | 불러온 엑셀은 브라우저 메모리에서만 처리. 서버로 전송하거나 디스크에 저장하지 않음 |
| 브라우저 저장 | 검토결과·의견만 Chrome의 localStorage에 임시 저장 (같은 PC·같은 브라우저에서만 보임) |
| 포함 라이브러리 | SheetJS Community Edition 0.18.5 (엑셀 읽기·쓰기, Apache-2.0, `src/vendor/`) |
| AI | 외부 AI를 호출하지 않음. 선별 사유·추가 확인사항·추가 점검항목 추천은 규칙과 집계로 생성 |
| 코드 | `src/` 아래 원본이 그대로 합쳐져 있어 HTML 파일 안에서 직접 읽어볼 수 있음 |

## 내부망 사용 방법

1. Chrome에서 HTML 파일을 엽니다 (더블클릭 또는 Chrome 창으로 끌어다 놓기).
2. **기준표 엑셀**을 준비합니다. 처음이면 **기준표 양식 내려받기**로 받은 `card-audit_reference-template.xlsx`에 실제 사내 기준을 입력합니다. 양식에 들어 있는 값은 교육용 가상값입니다.
   - `계정코드`: G/L 계정, G/L 계정명, 허용 가맹점업종(쉼표 구분), 건당 한도(원)
   - `업종코드`: 업종코드, 가맹점업종, 제한구분(금지/사전승인/주의/일반)
   - `공휴일`: 일자, 명칭 (주말은 자동 계산)
   - `점검기준`: 규칙ID, 점검항목, 위험가중치
   - `직원마스터`: 사번, 이름, 부서, 근무지 (R13 근무지 판단)
   - `휴가내역`: 사번, 이름, 휴가구분, 시작일, 종료일 (R17)
3. **엑셀 불러오기**로 기준표 엑셀과 SAP 추출 엑셀을 함께 고릅니다. 월별 파일은 나눠 불러와도 승인번호 기준으로 누적됩니다. SAP 파일의 시트 이름은 상관없고, 첫 행에 `승인번호`·`전표금액` 컬럼이 있으면 거래 시트로 인식합니다.
4. 점검 대상월을 고르고, 목록에서 건을 눌러 검토결과(적정/소명요청/부적정)와 의견을 입력합니다.
5. **결과 엑셀 저장**으로 `card-audit_result_YYYY-MM.xlsx`를 저장해 감사조서 증적으로 보관합니다. 이 파일을 다음에 SAP 엑셀과 함께 불러오면 검토결과·의견이 복원됩니다.

기준값(심야 시간대, 분할결제 간격 등)은 화면의 **점검 기준값** 탭에서 바로 바꿀 수 있지만 저장되지 않습니다. 계속 쓸 값은 기준표 엑셀에 반영하세요. 기준표만 바꾸는 경우에는 HTML을 다시 반입할 필요가 없습니다.

## 외부망에서 수정 → 재반입 절차

1. 내부망에서 문제를 **말로만** 정리해 옵니다. 실제 데이터·화면 캡처·결과 파일은 가져오지 않습니다.
2. 외부망에서 같은 상황을 가상데이터로 재현해 `src/`를 고칩니다.
3. 빌드: `./offline/build.sh 1.1` → `dist/법인카드점검_v1.1.html` 생성
4. 검증: `node offline/verify.js data/법인카드_가상데이터_202509-202608.xlsx` → 6개 항목이 모두 **통과**여야 반입합니다.
5. 아래 변경 이력에 바뀐 내용을 적고, HTML과 함께 반입 신청합니다.

## 알려진 제약

- Internet Explorer에서는 동작하지 않습니다 (Chrome 기준).
- 파일로 연 페이지에서는 한글 파일명이 무시될 수 있어 저장 파일명은 영문입니다.
- 검토결과·의견은 브라우저에 임시 저장되므로, Chrome 인터넷 기록을 지우면 사라집니다. 결과 엑셀로 보관하세요.
- 회사 보안 정책이 로컬 HTML 파일의 스크립트 실행을 막으면 동작하지 않습니다. 반입 전에 정보보호팀에 확인하세요.
