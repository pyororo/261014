# 법인카드 사용 적정성 점검 PoC

AI 기반 법인카드 사용 적정성 점검 지원(감사부) PoC입니다. 요구사항은 [CLAUDE.md](CLAUDE.md)를 따릅니다.
모든 데이터는 교육용 **가상 데이터**입니다.

## 진행 단계

- [x] 1단계: 엑셀 읽기·전처리(텍스트 컬럼, 승인일시, 휴일, 취소 상계), 월 필터·거래 목록·월별 요약
- [x] 2단계: R01~R07·R09·R15 규칙 + 위험점수·등급, 점검대상월 선별 화면, 기준값·가중치 설정
- [x] 3단계: AI 선별 사유·추가 확인사항·R13 의미 불일치·FP 저위험 조정, 건별 상세 화면
- [ ] 4단계: 기간 대시보드 T-R1~T-R4
- [ ] 5단계: 정답지 대조, 결과 엑셀 다운로드

## 실행 방법

```bash
pip install -r requirements.txt
# 엑셀을 data/ 폴더에 둠 (저장소에는 올리지 않음)
#   data/법인카드_가상데이터_202509-202608.xlsx
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다. data/ 에 파일이 없으면 왼쪽 사이드바에서 엑셀을 업로드하면 됩니다.

## 1단계 전처리 규칙 (CLAUDE.md 2-1)

| 항목 | 처리 |
|---|---|
| 텍스트로 읽는 컬럼 | G/L 계정, 승인시간, 예산부서, 업종코드, 가맹점사업자번호 |
| 승인일시 | 승인일(YYYYMMDD) + 승인시간(HHMMSS) |
| 휴일여부 | 토·일 또는 `공휴일` 시트에 있는 날 (SAP `상태` 컬럼은 쓰지 않음) |
| 취소 상계 | 취소건마다 같은 카드·가맹점·절대금액의 매입건 중 승인일시가 가장 가까운 미매칭 건과 짝지음. 짝지은 두 건은 분석 대상에서 제외 |

## 2단계 선별 규칙 (CLAUDE.md 2-2, 2-4)

규칙 코드는 `src/rules.py`. 기준값·가중치 기본값은 `점검기준(가상)` 시트에서 읽고, 화면 왼쪽 "점검 기준값 설정"에서 바꿀 수 있습니다.

| 규칙 | 구현 |
|---|---|
| R01 휴일 | 1단계 휴일여부 |
| R02 심야 | 승인시각 23시 이상 또는 06시 미만 |
| R03 제한업종 | 업종코드 시트 제한구분 = 금지·사전승인 (금지면 등급 무조건 '상') |
| R04 분할결제 | 동일 카드·가맹점·승인일에서 연속 간격 60분 이내 묶음이 2건 이상이고 합계 > 계정 건당한도 |
| R05 건당한도 | 전표금액 > 계정 건당한도 |
| R06 적요부실 | 적요 공란·5자 미만, 또는 접대비 계정인데 상대방 표기(ㅇㅇㅇ·직함·n인/n명) 없음 |
| R07 계정-업종 | 가맹점업종이 계정의 허용업종에 없음 |
| R09 중복결제 | 상계 후 남은 건 중 동일 카드·가맹점·금액·승인일 2건 이상 |
| R15 정산지연 | 회계일자 − 승인일 > 60일 |

점검대상월 선별 = 그 달 승인 건 중 규칙에 1개 이상 걸린 건 + 그 달에 회계처리된 정산지연(R15) 건.

## 3단계 AI 코멘트 (CLAUDE.md 2-5)

코드는 `src/ai.py`. Claude API 키가 없으면 CLAUDE.md 4장의 대체 방식대로 **규칙 기반 템플릿 문장**으로 생성합니다.

| 항목 | 동작 |
|---|---|
| 선별 사유 | 걸린 규칙 + 거래정보로 한 문장 작성 (예: "…골프장 1,160,000원 결제: 휴일(토요일) 사용, 골프장은 사전승인 업종…") |
| 추가 확인사항 | 규칙별 확인 항목 (금지업종 → 소명·환수 검토, 접대비 적요 부실 → 상대방·목적 확인 등) |
| R13 의미 불일치 | 결재문서제목의 비용 항목(하이패스·주유·택시·항공·숙박 등)과 실제 업종이 다르거나, 여비교통비 계정인데 근무지 안 회식·식사(직원마스터 근무지 기준)면 표시. 가중치 2 |
| FP 저위험 조정 | 걸린 규칙이 휴일·심야뿐이고 적요에 사전승인 문서번호(GW-YYYYMM-NNN)가 있으면 규칙당 1점 감점(최소 1점) |
| Claude API (선택) | `ANTHROPIC_API_KEY`를 설정하면 건별 상세에서 "Claude로 코멘트 다시 생성" 버튼이 나타남. 가상 사용지침(부록 A)과 거래 1건만 전송 |

AI 결과는 최종 판단이 아닌 참고자료라는 문구를 화면에 고정 표시합니다.
