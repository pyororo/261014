# 법인카드 사용 적정성 점검 PoC

AI 기반 법인카드 사용 적정성 점검 지원(감사부) PoC입니다. 요구사항은 [CLAUDE.md](CLAUDE.md)를 따릅니다.
모든 데이터는 교육용 **가상 데이터**입니다.

## 진행 단계

- [x] 1단계: 엑셀 읽기·전처리(텍스트 컬럼, 승인일시, 휴일, 취소 상계), 월 필터·거래 목록·월별 요약
- [ ] 2단계: R01~R09, R15 규칙 + 위험점수·등급
- [ ] 3단계: AI 사유·추가확인사항·R13
- [ ] 4단계: 기간 대시보드 T-R1~T-R4
- [ ] 5단계: 정답지 대조, 결과 엑셀 다운로드

## 실행 방법

```bash
pip install -r requirements.txt
# 엑셀을 data/ 폴더에 둠 (저장소에는 올리지 않음)
#   data/법인카드_가상데이터_202509-202608.xlsx
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다. data/ 에 파일이 없으면 왼쪽 사이드바에서 엑셀을 업로드하면 됩니다.

## 1단계 전처리 규칙 (CLAUDE.md 2-1)

| 항목 | 처리 |
|---|---|
| 텍스트로 읽는 컬럼 | G/L 계정, 승인시간, 예산부서, 업종코드, 가맹점사업자번호 |
| 승인일시 | 승인일(YYYYMMDD) + 승인시간(HHMMSS) |
| 휴일여부 | 토·일 또는 `공휴일` 시트에 있는 날 (SAP `상태` 컬럼은 쓰지 않음) |
| 취소 상계 | 취소건마다 같은 카드·가맹점·절대금액의 매입건 중 승인일시가 가장 가까운 미매칭 건과 짝지음. 짝지은 두 건은 분석 대상에서 제외 |
